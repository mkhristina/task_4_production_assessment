# Оценка состояния производственных подразделений

## 1. Описание проекта

Проект предназначен для оценки состояния производственных подразделений на основе производственных и финансовых показателей.

В программе используются два метода оценки:
- **Нечёткая логика** — для оценки состояния подразделения по заданным правилам.
- **Нейронная сеть MLPClassifier** — для классификации состояния подразделения и расчёта вероятностей классов.

Программа позволяет анализировать данные, строить графики, оценивать качество моделей и проверять показатели нового подразделения.

## 2. Используемые технологии

- Python
- Pandas
- NumPy
- Matplotlib
- scikit-learn
- scikit-fuzzy

## 3. Структура проекта

- `menu.py` — запуск программы и главное меню.
- `main.py` — основной модуль проекта.
- `analysis.py` — анализ данных и построение графиков.
- `fuzzy_model.py` — модель нечёткой логики.
- `ml_model.py` — обучение и оценка нейронной сети.
- `compare_models.py` — сравнение моделей.
- `data.csv` — исходные данные.
- `fuzzy_results.csv` — результаты работы нечёткой модели, если файл сформирован.
- `ml_test_results.csv` — результаты тестирования нейронной сети.
- `model_comparison.csv` — результаты сравнения моделей.
- `graphs/` — папка с графиками.
- `requirements.txt` — список необходимых библиотек.

## 4. Установка библиотек

Перед запуском программы необходимо установить необходимые библиотеки.

Откройте терминал в папке проекта и выполните команду:

```bash
pip install -r requirements.txt
```

## 5. Запуск программы

Для запуска программы выполните команду:

```bash
python menu.py
```

После запуска появится главное меню.

## 6. Возможности программы

В главном меню доступны следующие функции:

1. Генерация или загрузка данных.
2. Просмотр основных показателей.
3. Построение графиков.
4. Проверка нечёткой модели.
5. Обучение нейронной сети.
6. Просмотр метрик и матрицы ошибок.
7. Оценка нового подразделения.
8. Сравнение методов оценки.
0. Выход из программы.

## 7. Результаты работы

В процессе работы программа может формировать CSV-файлы с исходными данными и результатами моделей, а также графики для визуального анализа.

Качество нейронной сети оценивается с помощью Accuracy, Precision, Recall и F1-score. Дополнительно используется матрица ошибок.

## 8. Примечание

Данные в проекте являются учебными и используются для демонстрации методов анализа данных, нечёткой логики и машинного обучения.

Результаты моделей следует рассматривать как вспомогательную оценку состояния производственного подразделения, а не как единственное основание для принятия управленческих решений.


## 9. Пример оценки нового подразделения

Для проверки программы были введены следующие показатели:

- Доходы: 8
- Расходы: 7
- Количество сотрудников: 66
- Производительность: 88
- Просроченные заказы: 4
- Доля брака: 7
- Выполнение плана: 77%

Результаты оценки:

- Рентабельность: 12,5%.
- Нечёткая модель: «Требует внимания», оценка 40,21.
- Нейронная сеть: «Проблемное».
- Вероятность класса «Проблемное»: 76,5%.

Модели дали разные результаты, поэтому показатели подразделения требуют дополнительного анализа.

## 10. Итоговый вывод

В ходе работы была разработана программа для оценки состояния производственных подразделений. Были подготовлены данные, построены графики и реализованы две модели: нечёткая логика и нейронная сеть.

При проверке нейронная сеть показала точность 83,75%, а нечёткая модель — 68,75%. На использованных тестовых данных нейронная сеть показала лучший результат.

Также была проведена оценка нового подразделения. Модели дали разные оценки, что показывает необходимость дополнительной проверки производственных показателей.
